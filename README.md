# Ecommerce-EDA-Project

## 📌 Project Overview

This project focuses on **E-Commerce EDA using Microsoft Excel Pivot Tables**.

The objective of this project is to analyze transactional data from different business perspectives such as **product performance, order status, referral sources, payment methods, coupon performance, and year-wise sales**.

Pivot Tables were used to summarize the raw data and identify important patterns and business insights.

---

## 🎯 Project Objectives

The main objectives of this project are:

* Analyze product-wise performance.
* Analyze order status-wise values.
* Identify the most effective referral sources.
* Compare different payment methods.
* Analyze coupon performance.
* Analyze year-wise sales performance.
* Generate meaningful business insights using Excel Pivot Tables.

---

## 🛠️ Tools Used

* **Microsoft Excel**
* **Pivot Tables**
* **Data Analysis**

# 📊 Pivot Table Analysis

## 1. Product Analysis

Product Analysis was performed to compare the total Unit Price across different products.

| Product         | Sum of Unit Price |

| Chair           |         63,307.53 |
| Desk            |         56,033.38 |
| Laptop          |         61,883.32 |
| Monitor         |         58,462.17 |
| Phone           |         58,533.94 |
| Printer         |         63,660.40 |
| Tablet          |         65,814.56 |
| **Grand Total** |    **427,695.30** |

### 🔍 Insight

**Tablet** has the highest Unit Price contribution with **65,814.56**, while **Desk** has the lowest with **56,033.38**.

# 🔍 Key Business Insights

Based on the Pivot Table analysis:

1. **Tablet** has the highest displayed product-wise Unit Price value.
2. **Cancelled** orders have the highest displayed value among order statuses.
3. **Instagram** is the highest-performing referral source.
4. **Online** is the highest-valued payment method.
5. **FREESHIP** has the highest displayed coupon-related Total Price.
6. **2023** has the highest displayed year-wise Total Price.
7. Cancelled and returned orders should be analyzed further to understand potential revenue loss.
8. Referral and coupon performance can be used to improve future marketing strategies.

---

# 💡 Business Recommendations

Based on the analysis, the following actions can be considered:

* Investigate the reasons behind high cancelled orders.
* Focus marketing efforts on high-performing referral sources such as Instagram.
* Evaluate the effectiveness of the FREESHIP coupon.
* Encourage convenient online payment methods.
* Monitor product-wise performance regularly.
* Analyze the decline in year-wise sales.
* Investigate returned orders to identify product or service issues.
